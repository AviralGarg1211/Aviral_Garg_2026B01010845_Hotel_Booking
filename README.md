This project focuses on cleaning and preprocessing the Hotel Booking dataset using Python, Pandas, and NumPy.
It includes data inspection, missing value identification, duplicate removal, and handling missing data using mean, median, and mode.
Incorrect data types are corrected, and unnecessary or constant columns are removed.
Feature engineering is performed to create useful columns.
The analysis covers hotel-wise bookings, cancellations, monthly trends, country-wise bookings, length of stay and ADR.
VS Code editor was used to write the code.
